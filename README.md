# پیکربندی خودرو — انتخاب محیط

یک نمایشگر سه‌بعدی (Three.js + Vite) از خودرو، با منوی انتخاب محیط:

| محیط | توضیح |
| --- | --- |
| ☀️ آفتابی | آسمان آبی، نور تند، سایه‌های واضح |
| 🌧 بارانی | آسمان ابری، باران، سطح خیس و انعکاسی، چراغ‌ها روشن |
| 🌇 غروب | نور نارنجی افق، آسمان بنفش، قرمز شدن رنگ بدنه |
| 🌙 شب | ستاره‌ها، نور ماه، چراغ‌های جلو با نورافکن |
| ❄️ برفی | مه، بارش برف، زمین سفید |

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس خروجی (پیش‌فرض `http://localhost:5173`) را باز کنید.

## امکانات

- چرخش خودرو با درگ ماوس، زوم با اسکرول، چرخش خودکار قابل خاموش کردن
- تغییر نرم (انیمیشنی) بین محیط‌ها: آسمان، مه، نور، زمین و ذرات هوا
- ذرات باران و برف با شیدر اختصاصی
- چراغ‌های جلو/عقب خودرو متناسب با محیط روشن می‌شوند
- انتخاب محیط در آدرس ذخیره می‌شود (`?env=night`)
- طراحی واکنش‌گرا و راست‌به‌چپ برای فارسی
